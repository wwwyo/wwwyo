L293D でモーターを回した。

L293D はモーターの向きと速さを Arduino から変えられるようにする IC。Enable に PWM を入れると速さ、Input 1・2 の HIGH/LOW の組み合わせで向きが変わる。正転・逆転・ブレーキ・惰性停止を試して、最後はジョイスティックを倒した向きと量でモーターを回せるようにした。

参考にしたのは Last Minute Engineers の [In-Depth: Control DC Motors with L293D Motor Driver IC & Arduino](https://lastminuteengineers.com/l293d-dc-motor-arduino-tutorial/)。記事はモーター2台で IN1〜IN4 を使っているけど、キットのモーターは1台なので片側だけ使った。

### 配線

- 電源は 9V 電池のスナップ（先が DC プラグ）を電源モジュールのジャックに挿し、ジャンパーで 5V を選んでブレッドボードのレールへ。左右の＋は別の電圧にできるが、GND は共通
- L293D の 8 番（VCC2、モーター用）は電源モジュールの 5V、16 番（VCC1、ロジック用）は Uno の 5V
- 4・5・12・13 番は GND。チップの中でつながっているけど、全部つなぐのが推奨。放熱も兼ねている。Uno の GND も共通にする
- Uno の 9 番 → 1 番（EN）、8 番 → 2 番（IN_1）、7 番 → 7 番（IN_2）、モーターは 3・6 番

### わかったこと

- 向きは IN_1・IN_2 で決まる。HIGH/LOW で正転、LOW/HIGH で逆転、両方同じでブレーキ。EN を 0 にすると惰性で止まる
- ブレーキの正体は逆起電力。回っているモーターは発電機になるので、両端がつながっていると電流が流れて、回転と逆向きの力になる。惰性停止は回路が開くので電流が流れない
- 電源を切った瞬間の跳ね返りは、L293D に内蔵されたダイオードが逃がしている
- PWM の値が低いとモーターは回り出さない
- `for` で 0→255 を 5 刻み・`delay(50)` で上げると、約 2.6 秒かけて加速する。`delay` が無いとループが数 ms で終わり、実質いきなり全開になる
- int 同士の割り算は小数が切り捨てられる
- 255 × 423 は int（Uno では 32767 まで）を超えるので long が要る
- `map` は範囲の外の値をそのまま外挿する。`constrain` か `if` で範囲内に収める
- 9V 電池（アルカリ）は 500mAh 前後で充電できない。キットのモーターは 100〜200mA が目安

### 失敗

- `analogWrite(EN, HIGH)` と書いていて、ほとんど回らなかった。HIGH は 255 ではなく 1 として扱われる。`analogWrite(EN, 255)` に直した
- ブレーキの行で IN_1 を 2 回書いていた
- ジョイスティックの正転側の `map` の引数の順番を間違えていた
- `else` が 400〜599 を拾っていて、`map` がマイナスを返していた

### コード

ジョイスティックの X を読んで、600 以上で正転、400 以下で逆転、間は止める。

```cpp
int x = analogRead(JOY_X);

if (x >= 600) {
  digitalWrite(IN_1, HIGH);
  digitalWrite(IN_2, LOW);
  analogWrite(EN, map(x, 600, 1023, 0, 255));
} else if (x <= 400) {
  digitalWrite(IN_1, LOW);
  digitalWrite(IN_2, HIGH);
  analogWrite(EN, map(x, 400, 0, 0, 255));
} else {
  analogWrite(EN, 0);
}
```
